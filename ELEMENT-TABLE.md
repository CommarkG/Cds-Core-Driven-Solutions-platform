# ELEMENT: TABLE

## Description
A data grid with sortable column headers, row numbers, data cells, and action buttons (Edit, Delete, Export) for managing lists of participants, groups, or other resources.

## When to Use
Displays lists of entities (participants, groups, goals, configurations) where users need to view, sort, search, and perform bulk actions.
