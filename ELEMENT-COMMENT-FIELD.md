# ELEMENT: COMMENT FIELD

## Description
A text input field in each table row that stores per-row notes and comments, with placeholder text "Add comment...".

## When to Use
Appears in every table row to allow users to add contextual notes about that specific item (participant notes, group comments, etc.).
