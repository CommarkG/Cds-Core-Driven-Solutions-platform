# ELEMENT: BUTTON

## Description
A clickable interactive element with clear action text that triggers a primary action (Create, Save, Export), secondary action (Cancel, Copy), or destructive action (Delete, Remove).

## When to Use
Appears in forms, tables, modals, and action bars to enable user interactions and trigger application events.
