Developer Wireframe Templates

Lean UX/UI blueprint templates for building consistent features without starting from scratch.

Purpose: Every developer building a UI should start with one of these templates. Copy → Customize → Build. Ensures consistency while speeding up development.

SECTION 5: LAYOUT GRID & SPACING

DESIGN TOKEN SPACING GRID
BASE UNIT: 8px SPACING VALUES (all multiples of 8): 8px ─ Smallest gap (between form label + field) 12px ─ Small gap (button group, cell padding horizontal) 16px ─ Medium gap (section spacing within container) 20px ─ Large gap (between major sections) 30px ─ Very large gap (between page sections) 40px ─ Extra large gap (page margin) COMPONENT HEIGHTS (locked): 32px ─ Badge, small button 40px ─ Standard button, form field, table row 48px ─ Large button 60px ─ Page header (with padding) TYPOGRAPHY SIZES (locked): 12px ─ Small text, labels 13px ─ Help text, metadata 14px ─ Body text, inputs 16px ─ Section headers 18px ─ Page subtitle 20px ─ Page title 24px ─ Main heading 28px ─ Hero heading WIDTHS: 400px max ─ Form/sidebar content 1000-1200px ─ Main content area 1400px max ─ Full container BORDER-RADIUS (locked): 0px ─ No radius (crisp) 4px ─ Standard (buttons, inputs, cards) 8px ─ Large (modals, large cards)
All spacing MUST use 8px grid. Non-multiples of 8 break the grid and cause alignment issues at scale.
All component heights MUST follow values above. No arbitrary 38px or 42px heights.
These are HARDWIRED in ETSC-DESIGN-TOKENS.md

How to Use These Templates

Template workflow:

  1. Identify what you're building: Dashboard? Form? Wizard?
  2. Find matching template: Standard Dashboard, Form Page, Multi-Step Wizard, etc.
  3. Copy template wireframe structure: Paste skeleton into your design/code
  4. Customize content: Change labels, fields, data, titles
  5. Apply design tokens: All colors/spacing from ETSC-DESIGN-TOKENS.md
  6. Verify against checklist: ETSC-DESIGN-CONSISTENCY-CHECKLIST.md
  7. Build/code: Implement with React, Vue, etc.
  8. Test: Run through flows, verify states, test responsiveness
