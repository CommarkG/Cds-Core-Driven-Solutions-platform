# COMPACTION PROTOCOL — FORMAL ANNOUNCEMENT

## EFFECTIVE IMMEDIATELY (Session S348+)

**Rule:** Every time autocompaction occurs, I AUTOMATICALLY prepare a one-click recovery prompt. User does not need to ask or remind me.

**Status:** HARDWIRED MANDATORY (like the communication protocol)

**Applies to:** All sessions, all domains, no exceptions

---

## WHAT THIS MEANS FOR YOU

### Before Compaction
When context reaches <5% and autocompaction is imminent:

1. **I prepare recovery context** — all session accomplishments, critical facts, files
2. **I create a recovery prompt file** — named `POST-COMPACTION-S{N}-RECOVERY-PROMPT.md`
3. **I save it to the CDS folder** — persistent, not in scratchpad
4. **I present it one-click ready** — copy file path, paste after compaction
5. **Done** — you don't have to think about recovery context

### After Compaction
When you enter the next session:

1. **Copy the recovery prompt file** — `POST-COMPACTION-S{N}-RECOVERY-PROMPT.md`
2. **Paste it into the chat** — one keystroke to restore full context
3. **That's it** — incoming AI has everything it needs to continue

---

## THE ONE-CLICK FORMAT

Every recovery prompt will be presented like this:

```
✅ POST-COMPACTION RECOVERY PROMPT IS READY

**File:** c:\Users\finky\Desktop\Claude Code\Cds - Core Driven Solutions\POST-COMPACTION-S{N}-RECOVERY-PROMPT.md

**To recover after compaction:**
1. Copy the entire contents of the file above
2. Paste it immediately into the next chat after compaction fires
3. That's it — full context will be restored

**Ready to trigger `/compact` now?**
```

That's it. Copy, paste, continue. No manual recovery prep.

---

## WHAT'S INSIDE THE RECOVERY PROMPT

Every recovery prompt includes:

✅ What was accomplished this session (5-10 bullet points)
✅ Critical facts next AI must know
✅ Files to read (in priority order)
✅ Immediate next steps (clear actions)
✅ External system status (requests pending?)
✅ Session summary (accomplished, blocked, ready)
✅ Recovery checklist (verify you've read everything)

**Everything between the triple backticks is copied verbatim into the next chat.**
