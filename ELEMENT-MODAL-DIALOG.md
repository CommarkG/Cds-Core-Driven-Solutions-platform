# ELEMENT: MODAL/DIALOG

## Description
An overlay window that appears on top of page content, requiring user action (confirmation, form submission, error acknowledgment) before returning to main page.

## When to Use
Confirms destructive actions (Delete, Clear), displays detailed forms, shows confirmation messages, or requests user input without leaving the page.
