System Architecture Overview

Data Flow & Integration with Phase 0

Goal Creation Flow:

Admin enters draft
→
AI refines core
→
Core locked
→
Scope presented
Bundle recommendation
→
Admin confirms
→
Goal created in decision-log
→
Immutable audit trail

Backend Integration Points:

  • Phase 0 Decision Log: Goal creation → immutable entry in decision-log.ts
  • Identity Gate: Admin authentication required (ADMIN tier only)
  • Authority Matrix: Permission checks (who can create goals, edit bundles)
  • Schema Checksum: Validate goal type + bundle + participants exist + match schema
  • Participant Profiles: Load from database, show capacity in UI
  • Recommendation Engine: Backend API calculates matching, suggests bundle

Schema Alignment:

  • Goal Type: Maps to canonical schema node (SCHEMA-GOAL-PERF-001, etc.)
  • Participants: Maps to canonical schema node (SCHEMA-PART-CSP-001, etc.)
  • Bundle: Maps to canonical schema node (SCHEMA-BUNDLE-PERF-ARCH-001, etc.)
  • Vocabulary: All references use glossary canonical names (no aliases in form)
