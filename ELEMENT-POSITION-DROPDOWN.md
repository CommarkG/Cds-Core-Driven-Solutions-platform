# ELEMENT: POSITION DROPDOWN

## Description
A specialized dropdown in each table row that allows users to select and change the row's position in the list, with automatic row number recalculation.

## When to Use
Appears in tables where rows can be reordered (participant lists, group hierarchies, priority-ordered items).
