### Decision 2: Prevention Protocol Stages (1-4)
- **Stage 1-3:** Complete, operational, ready to enforce
- **Stage 4:** Parked, documented, ready to build after core proves stable
- **Why parked:** Can't measure learning without 4+ weeks of data. Don't over-optimize early.
- **Impact:** Prevention is mechanical from day one. System improves with every escalation.

### Decision 3: Tier 1 Mandatory (No Shortcuts)
- **What:** Every Tier 2 action checks "Is Tier 1 complete?"
- **Bypass:** Only explicit Yariv waiver (logged + audited)
- **Why:** Tier 1 catches fundamental issues early. Skipping costs 10x later.
- **Impact:** Quality is enforced mechanically, not hoped for.

### Decision 4: PCR Mandatory (Problem-Centered Recommendation)
- **What:** All communication (between me & you, between systems) follows PCR format
- **Format:** Problem + Context + Recommendation + Reasoning (no hidden assumptions)
- **Why:** Prevents false assumptions. Makes reasoning explicit.
- **Impact:** Every decision is auditable. Every escalation is documented.

### Decision 5: "Nothing Stands Alone"
- **What:** Every system must reference schema. When schema doesn't fit, create new schema entry (not new system).
- **Why:** Prevent complication. Enhance existing patterns, don't build parallel ones.
- **Impact:** Simplicity. Coherence. Fewer systems to maintain.
